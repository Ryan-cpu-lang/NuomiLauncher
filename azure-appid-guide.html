🆕 2026-11-05 实测新增的「门槛零」：个人微软账号不能直接注册应用了。
微软自 2024 年 6 月起要求「所有应用必须注册在 Microsoft Entra 目录（租户）里」， 取消了过去「只关联个人账号、不属于任何目录」的注册方式。只用个人 Microsoft 账号 （Outlook / Hotmail / Xbox / 买 MC 的那个账号）登录 Azure 门户，点「新注册」会被直接拦下： 在目录外部创建应用程序的功能已被弃用；进 Entra 管理中心还会报 AADSTS16000 ... account does not exist in tenant 'Microsoft Services'， 目录里用户数 / 应用数全是 0。先看 ⓪，再回来做 ①。
⚠️ 必须由你本人操作的步骤：登录微软账号、以及（若走 Azure 免费账号）手机号 / 卡片身份验证。
账号、密码、验证码、卡片信息只能你自己输，助手不会碰、也不需要你告诉我。做完说一声， 剩下的建目录、注册、开权限、复制 ID、写配置都可以交给助手接管。

⓪先拿到一个 Microsoft Entra 目录（租户）

A

最省事：你已经有可用的工作 / 学校账号或其它租户

用那个账号登录，或请租户管理员把你加为成员 / 全局管理员。然后在 Azure 门户右上角头像 → 切换目录，切过去就能直接注册应用。完全免费、不用绑卡， 这条最优先试。

B

普通个人账号的通用解：注册 Azure 免费账号

🔗 https://azure.microsoft.com/free

注册后会自动生成一个 Entra ID Free 租户（xxx.onmicrosoft.com）， 你自动成为全局管理员，之后注册应用永久可用、不产生费用。

注意：微软会要求手机号 + 信用卡做身份验证（有一笔临时预授权，会退回、不扣费）， 且卡需为实体卡、不接受预付 / 虚拟卡。这一步只能你本人填，属于「免费但要有卡」的门槛。

C

另外两条（一般不推荐）

  • M365 开发人员计划（E5 sandbox 租户）：2026 年资格已收紧，通常要 Visual Studio Professional/Enterprise 订阅或合作伙伴资格，纯个人多半会显示「不符合资格」。
  • External ID 免费试用租户（aka.ms/ciam-free-trial）：不用绑卡， 但只有 30 天、到期租户被删，而 Mojang 审核要按周排队，client ID 会跟着失效， 只适合临时验证流程。

①注册 Azure 应用

1

登录 Azure 门户，确认「当前目录」是真实租户

右上角头像里应显示一个 xxx.onmicrosoft.com 的目录名，而不是一串纯 GUID 的隐式目录。 用买 Minecraft 时那个微软账号登录（审核表会拿这个邮箱跟 Azure 门户交叉核对）； 若你走的是 ⓪-B 新建的租户，用同一账号切过去即可。

✘ 页面上若出现黄色警告条「这些应用程序与账户关联，但不在目录中」，说明 ⓪ 还没过，别往下点了。

🔗 https://portal.azure.com
2

进入应用注册页

顶部搜索框输入 Microsoft Entra ID → 左侧菜单 应用注册 / App registrations → 新注册 / New registration。

也可以直接走直达链接：https://entra.microsoft.com/#view/Microsoft_AAD_RegisteredApps/ApplicationsListBlade

3

填名称（有命名禁词，别踩）

名称：NuomiLauncher

Mojang 明确要求应用名不能包含：Mojang、Minecraft、Microsoft、Live、Xbox、Discord、Hypixel。所以别写成「NuomiMinecraftLauncher」。NuomiLauncher 是合规的，随便换个自己喜欢的名字也行。

4

选「支持的账户类型」——最容易选错的一步

✅ 选第 3 项：任何组织目录中的账户和个人 Microsoft 账户
（Accounts in any organizational directory and personal Microsoft accounts）

第 4 项「仅个人 Microsoft 账户」也可以。启动器登录用的是 consumers 端点，必须让个人微软账号能用。

✘ 千万别选第 1 项「仅此组织目录中的账户」，那样个人账号根本登不进来。

5

重定向 URI 留空 → 点「注册 / Register」

设备码流不需要回调地址，留空就行。要是页面非要你选，就选 Mobile and desktop applications 并填 https://login.microsoftonline.com/common/oauth2/nativeclient。

6

打开公共客户端流（不做这步等于白注册）

创建完成后进左侧 身份验证 / Authentication → 往下找到 允许公共客户端流 / Allow public client flows → 设为 Yes → 保存。

✘ 不开这个，设备码流仍会报 AADSTS700016 unauthorized_client。

7

回到「概览 / Overview」，抄下两个 ID

  • 应用程序(客户端) ID / Application (client) ID —— 启动器要填的就是它
  • 目录(租户) ID / Directory (tenant) ID —— Mojang 审核表单必填，别忘了

两个都是 UUID 格式。别拿成「对象 ID / Object ID」，那个没用。

②提交 Mojang AppID 审核

新注册的 Azure 应用默认没权限调 Minecraft Java API，login_with_xbox 会 403 Invalid app registration。必须去 aka.ms/mce-reviewappid 提交一次审核，每周审一批，重复提交不会更快。下面按表单真实字段逐项填：

表单字段填什么
1. 已阅读 EULA 与使用指南选 Yes（aka.ms/mcusageguidelines）
2. Contact Information注册 Azure 应用时用的那个微软账号邮箱
3. What type of requestNew AppID for Approval
4. Application NameNuomiLauncher（和 Azure 里一致，不含禁用词）
5. Application ID第 7 步抄的 Application (client) ID，一次只提交一个
6. Tenant ID第 7 步抄的 Directory (tenant) ID（新应用必填）
7. Associated website or domainhttps://github.com/Ryan-cpu-lang/NuomiLauncher
8. Justification用下面这段英文模板
9. Any other information留空或填 N/A

第 8 项 Justification 模板（表单是英文，用英文更容易过；重点强调「不绕过正版验证」，这是官方最看重的）：

NuomiLauncher is an open-source, non-commercial Minecraft launcher written in the Nuomi programming language. We request access to the Minecraft Java Edition Game Service APIs so that legitimate game owners can sign in with their own Microsoft account (OAuth 2.0 Device Authorization Grant, RFC 8628) and launch the Java Edition they have purchased.

The launcher always performs the full Microsoft -> Xbox Live -> XSTS -> Minecraft Services authentication chain and verifies game ownership before starting the game. It does not bypass, disable, or weaken any authentication, ownership, or license check, and it works normally with online-mode servers. No game assets are redistributed; all downloads come from Mojang's official endpoints or public mirrors.

Source code: https://github.com/Ryan-cpu-lang/NuomiLauncher
合规底线：官方明确写了「应用必须验证用户拥有游戏、并在进入游戏前要求认证」，绕过正版验证的启动器一律不批。NuomiLauncher 走的就是完整正版链路，这点没问题 👌

③拿到 client ID 之后

A

填进启动器

GUI：侧栏「账户登录」→ 微软 client_id 输入框 → 粘贴 → 「保存」。
或者直接写文件：%USERPROFILE%\.nuomi-mc\ms_client_id.txt（纯一行 UUID，不要引号、不要空格）。

把 ID 发给助手也可以，助手会直接帮你写好并验证。

B

审核批下来前

微软登录会卡在 login_with_xbox 403，这是正常的等待状态，不是代码 bug。这段时间 LittleSkin 外置登录和离线模式都照常用。

通过之后点「使用微软账号登录」→ 浏览器自动打开 → 设备码已自动进剪贴板，Ctrl+V 即可；之后过期了点右边的「刷新」静默续期，不用再开浏览器。

⚠️常见坑速查

  • 点「新注册」弹「在目录外部创建应用程序的功能已被弃用」 → 2024-06 起的平台变更，个人账号没有 Entra 租户；回到 ⓪ 先建目录，换浏览器 / 重登都无效。
  • AADSTS16000 ... account does not exist in tenant 'Microsoft Services' → 同上，Entra 管理中心对个人 MSA 账号拿不到目录令牌。
  • unauthorized_client / AADSTS700016 → 公共客户端流没开 Yes，或还在使用已被下架的公共 ID 00000000402b5328。
  • 登录时提示账号类型不支持 → 「支持的账户类型」选成了仅组织目录，回去改成含「个人 Microsoft 账户」那项。
  • Invalid app registration / 403 → Mojang 审核还没通过，只能等。
  • 审核表单被打回 → 多半是应用名含禁用词，或 Justification 没写清「验证游戏所有权」。
  • tenant ID 别填到启动器里：代码用的是固定的 consumers 端点，自己的 Directory (tenant) ID 只是给审核表单用的。
